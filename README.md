# 乌兰木伦镇蔬菜、瓜果生产采集系统 (离线优化版)

单HTML文件的离线蔬菜、瓜果生产数据录入与汇总系统，适用于乌兰木伦镇 A412 数据采集工作。无需服务器、无需安装，打开浏览器即可使用，所有数据浏览器本地存储（LocalStorage）。

## 主要功能

- **数据录入**：按作物分类录入播种面积（亩）与产量（吨），支持叶菜类、白菜类、甘蓝类、根茎类、瓜菜类、豆类、茄果类、食用菌、瓜果类等指标。
- **自动汇总**：分组自动计算面积与产量合计，并按平均单产自动推算产量。
- **参数设定**：为每个作物设置最小/平均/最大单产参数，用于自动计算与校验。
- **历史批次**：将录入数据保存为批次，支持查看历史、加载历史、删除记录。
- **导出数据**：支持导出全部数据为 JSON 备份，支持累计汇总清单导出为 CSV。
- **备份恢复**：自动每 5 分钟本地备份，支持从备份恢复数据。
- **离线优化**：纯前端实现，断网也可正常使用。

## 使用方法

1. 下载 `veg-fruit-data-entry-summary.html`。
2. 用任意现代浏览器（Chrome / Edge / Firefox 等）打开即可。
3. 在“数据录入”标签页选择填表单位、输入种植户姓名与填表日期。
4. 在表格中录入各作物的播种面积与产量，面积输入后会按平均单产自动推算产量。
5. 点击“保存此批次”将数据保存为历史批次。
6. 切换到“汇总历史”查看所有批次累计汇总，可导出 CSV。
7. 切换到“参数设定”调整各作物的单产参数。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（无框架、无依赖）
- LocalStorage 本地持久化
- 响应式布局，支持移动端

## 注意事项

- 数据仅保存在浏览器本地 LocalStorage 中，清除浏览器数据或更换浏览器/设备会导致数据丢失，建议定期使用“导出数据(JSON)”进行备份。
- 本系统为离线单机版，不支持多用户并发与云端同步。
